# Cheezy Bytes — Digital Card (static site)

Plain HTML/CSS/JS, no build step — ready to host on GitHub Pages.

## Deploy

1. Create a new GitHub repo (e.g. `cheezy-bytes-card`).
2. Upload every file in this folder (`index.html`, `style.css`, `script.js`, `.nojekyll`) to the repo root.
3. In the repo, go to **Settings → Pages**, set **Source** to the `main` branch / `/ (root)`, and save.
4. Your card will be live at `https://<your-username>.github.io/<repo-name>/`.

All links (call, WhatsApp, directions, order) are relative to nothing — no config needed, it works at any URL/subpath.
